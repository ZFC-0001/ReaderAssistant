# 协作约定

- 本目录是 Android 本地事务助手开发骨架，不把 TODO/模拟样例描述为已实现功能。
- 遵守 docs/三人分工与TODO.md。C 不修改业务/数据库/系统权限实现；A 不直接写任务库。
- contract/ 为公共契约，由 B 维护并与 A/C 协调。先改契约和样例，再改各自实现。
- 所有任务写入经 TaskRepository/业务用例。确认前后 ID 不变；正式变化必须经过用户确认。
- 来源时间与读取时间分开；日期精度不得补出 23:59。取消、延期短句不能在规则层丢掉。
- 新能力未就绪返回 Unavailable/Blocked/NOT_IMPLEMENTED，不返回伪成功或模拟 AI。
- 不记录来源原文、截图、模型输入到常规日志，不引入云端推理，不自动下载核心模型。
- 不通过 isAccessibilityTool/root/数据库破解绕过限制；微信聊天使用已测不可读结论规划 OCR spike。
- 构建链版本先保持；新增依赖和 Compose/Hilt/DataStore 迁移先说明影响并验证构建。
- 修改状态/事务/去重/提醒代码后运行相关测试，更新 docs/验证记录.md，区分 JVM 与设备结果。
