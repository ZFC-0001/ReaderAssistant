# A02-2g / A02-2h：系统模糊防护根因与聊天OCR候选验证

日期：2026-11-12。只修改A的capture/ocr、对应测试和A文档；不修改公共配置、B/C、任务库或接口。

## 本轮结论

当前手机开启screen_share_protection_on=1时，MediaProjection交给OCR的实际输入被强烈模糊。临时改为0、保持相同捕获与OCR代码后，导出图像清晰，原图识字从接近空白增加到302字符。这是本机实测前后对照，不推及所有系统/版本。

另一个问题是固定白页二值化阈值200：绿色气泡亮度低于该阈值，会与深色字一起变黑。合成白底图的3/3不能代表绿色聊天气泡。本轮保留原始失败结果，未放宽匹配规则或替换错字。

## 授权与调试方法变化

用户先明确同意临时导出测试图，之后明确要求测试阶段按最快方式定位。依据这一新增授权，本轮使用ADB物理截图、私有PNG/RGBA导出、实际OCR文本、电脑端像素预处理和设备端导入回放，不再把“不保存/不上传”的成品边界用于阻止已批准的测试诊断。

DebugFrameExport仅debug显式开关启用，默认关闭，保存私有测试PNG/RGBA及SHA；OcrDebugImageTest只读固定私有测试文件。产品代码没有新增INTERNET权限、云端推理或图片自动上传。真实截图/原文报告留在工作区work/a02-2g与work/a02-2h，未复制进代码仓库或A证据目录；本目录只保存计数、哈希、授权及范围记录。
