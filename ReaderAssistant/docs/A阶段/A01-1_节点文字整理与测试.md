# A-01.1：节点文字整理与测试

日期：2026-11-11。范围：A内部的节点遍历/文字整理，不涉及OCR、模型、任务库或公共contract改动。

## 本部分解决什么

把QQ Android节点读取与纯文字整理分开，后者可以用合成节点在JVM测试。

- 保留根/子节点顺序，order连续；修剪两端空白，忽略空内容。
- 同一节点的text与contentDescription相同只保留一次。
- 重叠窗口/重复根按节点身份去重；不同节点即使正文相同也保留。
- 每次追加前检查250文字块上限，避免text＋description产生251块。
- 深度、节点读取和文字块数有边界；空子节点/重复访问也消耗读取预算。
- 缺节点、失效节点、预算不足均标记truncated；权限异常停止后续读取。
- 不解释任务，不猜发送人、日期或消息身份；本次节点去重不是持久任务去重。
